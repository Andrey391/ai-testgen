## Принятые решения (13 октября 2026)

1. **Ввод новых требований в «Конвейере» — убрать.** Требования вводятся и проверяются только во вкладке «Требования».
   API `/jobs` с `links`/`text` остаётся для MCP и CI (5.4).
2. **Несколько сессий Studio у одного пользователя — да**, например когда человек работает на нескольких проектах.
   Лимит на пользователя — настройкой (3.1).
3. **«Ждёт вас» — выпадающий список у колокольчика в шапке**, без отдельной вкладки (2.2, 5.1, 5.2).

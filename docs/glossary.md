# Словарь терминов студии

Названия функций, которые в интерфейсе остаются латиницей, и термины, которые студия понимает по-своему. В интерфейсе у
латинских названий есть русская подсказка (наведите курсор).

## Функции

| В интерфейсе | По-русски | Что делает |
|---|---|---|
| Studio | Студия записи теста | Экран, где агент проходит сценарий в браузере, а человек подтверждает и правит шаги |
| Auto-Pilot | Автопилот | Агент выполняет шаги сам, без подтверждения каждого; выключен — каждый шаг ждёт «Выполнить шаг» или «Отклонить» |
| Live View | Живой экран | Браузер сессии в реальном времени; у API-теста — запросы и ответы |
| Record & Play | Запись действий | Клик по элементу на живом экране делает с ним то же, что пользователь (кнопка — клик, поле — ввод текста, список — выбор), и становится шагом |
| Element Picker | Выбор элемента | Сначала выбирается действие или проверка, затем клик по элементу на живом экране |
| Planner | Планировщик | Обходит сайт по ссылкам (только GET, без форм) и строит карту страниц — по ней конвейер предлагает сценарии, когда ТЗ нет |
| MCP | Протокол подключений | Способ подключить внешние системы (Jira, Confluence, Zephyr Scale, Playwright MCP) и работать со студией из IDE |

## Работа с тестами

| Термин | Значение |
|---|---|
| Сценарий | Что проверить, обычным языком: шаги пользователя и ожидаемый результат. Из сценария агент записывает тест |
| Тест (автотест) | Исполняемый список шагов: действия и проверки с локаторами элементов |
| Шаг | Одно действие (клик, ввод, переход) или одна проверка теста |
| Локатор | Способ найти элемент на странице: `data-testid`, `#id`, роль и имя, текст, CSS-путь. У шага их несколько |
| Самолечение | Когда все локаторы шага сломались, ИИ находит элемент заново; новый локатор ждёт решения человека («на ревью») |
| Модуль | Повторяющаяся цепочка действий, общая для нескольких тестов: правится в одном месте |
| Прогон | Один запуск теста в новом браузере: результат, скриншоты, trace, события браузера |
| Набор | Запуск многих тестов разом (все или по тегам) — регрессия |
| Нестабильный тест | Упал и прошёл при перезапуске, или часто меняет результат |
| Карантин | Тест, падение которого не валит набор, пока его чинят |
| Мутационная проверка | Тест прогоняется на «испорченных» версиях страницы и обязан на каждой упасть; иначе его проверки слабые |

## Процесс

| Термин | Значение |
|---|---|
| Конвейер | Сквозной процесс: проверенные требования → сценарии → тесты → прогон → проверка качества → публикация |
| Ревью требований | Проверка ТЗ отдельным ИИ-ревьюером: дефекты документа и расхождения с жизненным циклом |
| Модель приложения | Сущности, их статусы и зависимости, роли и учётные записи, данные стенда — «Проект → Тестовые данные» |
| Жизненный цикл | Статусы сущности и переходы между ними (кто и каким действием переводит). Тесты генерируются только по подтверждённому |
| Скилл | Инструкция для ИИ на этапе процесса (формат SKILL.md): правила команды, примеры, стиль |
| Ждёт вас | Счётчик решений человека в шапке: ожидания конвейера, замечания ревьюера, обновления модели, самолечение |

# Студия в закрытом контуре

Студия может работать без доступа в интернет: модель запускается на своём сервере, браузеры,
axe-core и MCP-серверы лежат в Docker-образе. Режим включает переменная `TESTGEN_OFFLINE=on`:

- никаких обращений к CDN — axe-core берётся из `TESTGEN_AXE_JS` (в образе: `/opt/testgen/axe.min.js`);
- MCP-серверы пресетов (`@playwright/mcp`, `mcp-zephyr-scale`) запускаются через `npx --offline`
  из кэша npm, заполненного при сборке образа;
- провайдер Claude недоступен, если его адрес не указывает во внутреннюю сеть (прокси);
- Planner, прогоны, мутации и экспорт не ходят наружу и раньше.

Экспортированные тесты (`.py`) качают axe-core с CDN только для проверок доступности; на машине без
интернета задайте им `TESTGEN_AXE_JS`.

## Быстрый старт

```bash
# на машине с интернетом: образ и веса модели
docker build -t ai-testgen .
huggingface-cli download Qwen/Qwen2.5-VL-7B-Instruct --local-dir ./models/Qwen2.5-VL-7B-Instruct
docker save ai-testgen vllm/vllm-openai > images.tar      # перенести в контур вместе с ./models

# в контуре
docker load < images.tar
docker compose up -d
docker compose logs studio      # пароль пользователя admin при первом запуске
```

`docker-compose.yml` поднимает студию и vLLM с моделью Qwen2.5-VL (видит изображения и вызывает
инструменты). Студия получает провайдера `local` из переменных `TESTGEN_LOCAL_LLM_URL` и
`TESTGEN_LOCAL_LLM_MODEL`, `TESTGEN_LLM_PROVIDER=local` делает его моделью по умолчанию для всех этапов.
Другие модели и цены — в «Проект → Модели ИИ».

## Какая модель и какие GPU

| Модель | Память GPU (bf16) | Пример сервера | Замечания |
|---|---|---|---|
| Qwen2.5-VL-7B-Instruct | ≈ 20 ГБ | 1 × L4 / A10 / RTX 4090 (24 ГБ) | Для пилота и простых сайтов; агенту нужен режим с подтверждением шагов |
| Qwen2.5-VL-32B-Instruct | ≈ 70 ГБ (AWQ ≈ 24 ГБ) | 1 × A100/H100 80 ГБ или 2 × 48 ГБ | Разумный баланс для корпоративных сайтов |
| Qwen2.5-VL-72B-Instruct | ≈ 150 ГБ (AWQ ≈ 45 ГБ) | 4 × A100 80 ГБ (2 × с AWQ) | Ближе всего к облачным моделям |

Числа ориентировочные: к весам добавьте память на контекст (KV-кэш), `--max-model-len 32768` для
агента достаточно. Текстовые модели без изображений тоже подойдут — агент работает по списку элементов
(«Скриншоты агенту: никогда»).

Для vLLM обязательны `--enable-auto-tool-choice` и парсер вызовов инструментов модели
(`--tool-call-parser hermes` для Qwen). Если модель всё же пишет вызов текстом (`<tool_call>{…}</tool_call>`),
студия его распознает.

## Перед пилотом

1. Запустите бенчмарк на выбранной модели: `python -m testgen.bench --provider local` (docs/bench.md).
   Результат сохранится в настройках модели; Auto-Pilot включится, только если доля успешных тестов
   выше порога проекта («Процесс генерации → Auto-Pilot не-Claude моделей»).
2. Смешанная схема тоже возможна: автор теста на локальной модели, анализ падений — на GigaChat (этап
   «Прогон» → провайдер).

# Юнит-экономика: сколько стоит тест

Нижняя граница цены — расходы заказчика на модели плюс наша поддержка. Расходы на модели студия
считает сама: у каждого запроса есть токены, у модели — цена за миллион токенов (в $ или ₽,
«Проект → Модели ИИ»). Где смотреть:

- сессия Studio и прогон — строка статуса («токены … ≈ $»);
- проект за месяц — «Процесс генерации → Лимиты расхода»: по этапам и моделям;
- дашборд проекта — средняя стоимость теста и сэкономленные часы;
- бенчмарк — стоимость теста на наборе сценариев (`docs/bench.md`).

## Формула

```
расход в месяц = N_новых × C_генерации
               + N_прогонов × p_самолечения × C_самолечения
               + N_падений × C_анализа
```

| Величина | Откуда взять |
|---|---|
| C_генерации — генерация теста (включая усиление проверок) | бенчмарк: «Стоимость теста»; проект: этап authoring / число тестов |
| C_самолечения — один вылеченный локатор | проект: этап run, запросы самолечения |
| C_анализа — разбор одного падения | проект: этап run, запросы анализа |
| p_самолечения — доля прогонов, где сломан локатор | история прогонов: прогоны с «self-healed» / все |
| N_новых, N_прогонов, N_падений | объём команды: тестов в месяц, прогонов набора × тестов, падений |

Прогоны без поломок моделей не касаются: локаторы, запасные варианты и проверки работают без LLM.
Мутационное тестирование тоже бесплатно.

## Пример (ориентир, уточнить по бенчмарку)

Команда из 5 человек: 100 новых тестов в месяц, набор из 400 тестов прогоняется 60 раз (ночью и на
каждое слияние), 2% прогонов с починкой локатора, 150 падений на разбор.

| Статья | Количество | Цена за единицу | В месяц |
|---|---|---|---|
| Генерация | 100 | $0.60 | $60 |
| Самолечение | 400 × 60 × 2% = 480 | $0.02 | $9.6 |
| Анализ падений | 150 | $0.03 | $4.5 |
| **Итого** | | | **≈ $74** |

На GigaChat или своей модели те же токены считаются по их цене (своя модель — только сервер и
электричество). Лимиты расхода на сессию, запуск конвейера и проект в месяц останавливают запросы при
превышении и предупреждают на 80%.

## Эффект для заказчика

Сэкономленные часы = время ручного прогона кейса (настройка проекта, «Ручной прогон кейса, минут») ×
число автоматических прогонов. Сокращение времени регрессии — главный эффект автоматизации для 68%
компаний (Russia Quality Report 2026): на дашборде это «Время регрессии» и его динамика.

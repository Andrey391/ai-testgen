# Примеры ходов

Каждый ход — ровно один вызов инструмента. Ref берётся только из последнего состояния страницы.

## Пример 1. Вход

Состояние страницы:
```
[e3] textbox "Логин"
[e4] textbox "Пароль" type='password'
[e5] button "Войти"
```
Ходы:
1. `fill` {"ref": "e3", "text": "{{username}}", "press_enter": false, "description": "Ввести логин"}
2. `fill` {"ref": "e4", "text": "{{password}}", "press_enter": false, "description": "Ввести пароль"}
3. `click` {"ref": "e5", "description": "Нажать кнопку «Войти»"}
4. `assert_url_contains` {"text": "/dashboard", "description": "Открылась главная страница"}

## Пример 2. Добавить товар в корзину

Состояние после поиска:
```
[e12] button "В корзину" (у карточки «Чайник»)
[e20] link "Корзина (0)"
```
Ходы:
1. `click` {"ref": "e12", "description": "Добавить «Чайник» в корзину"}
2. Новое состояние: `[e20] link "Корзина (1)"` → `assert_element_text` {"ref": "e20", "text": "Корзина (1)", "description": "В корзине один товар"}
3. `finish` {"status": "passed", "summary": "Товар добавлен, счётчик корзины = 1", "evidence": "Шаг 2 проверяет, что счётчик корзины показывает 1"}

## Пример 3. Ошибка и исправление

Ход `click` {"ref": "e99", ...} вернул ошибку «There is no element with ref 'e99'». Правильно:
посмотреть на последнее состояние страницы, найти нужный элемент по тексту и повторить с его ref.
Если мешает всплывающее окно — сначала закрыть его (`click` по кнопке «Закрыть» или `press_key` Escape).

## Чего не делать
- Не вызывать два инструмента за ход и не писать вызов текстом вместо инструмента.
- Не завершать сценарий без проверки результата: `finish` со статусом passed примут только после проверки.
- Не оплачивать, не отправлять и не удалять — дойти до этой точки, проверить, завершить.

# Результат прогона в Zephyr Scale

- Исполнение (test execution) создаётся для тест-кейса с указанным ключом.
- Тестовый цикл: если задан в настройках — используй его; иначе найди открытый цикл с названием
  «AI Test Generator — <дата прогона>» и создай его, если такого нет. Все прогоны одного дня
  попадают в один цикл.
- Статус: прогон прошёл → Pass, упал → Fail, не удалось выполнить (ошибка окружения) → Blocked.
  Нестабильный прогон (flaky: упал, при перезапуске прошёл) → Pass, а в комментарии — «нестабилен».
  Используй названия статусов, которые есть в проекте (проверь список статусов, если не уверен).
- Комментарий: итог в 1–3 строки — сколько шагов выполнено, на каком шаге падение и текст ошибки,
  вывод анализа (дефект продукта / проблема теста / окружение), число самовылеченных локаторов.
- Если есть результаты по шагам — проставь статус каждого шага.
- Ничего не удаляй. Вызови done с ключом исполнения.

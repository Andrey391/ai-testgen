# Результат прогона в Allure TestOps

- Запуск (launch): найди открытый запуск «AI Test Generator — <дата прогона>» в проекте, иначе создай его. Все прогоны
  одного дня попадают в один запуск.
- Результат (test result) — для тест-кейса с указанным ID: статус passed / failed / broken (ошибка окружения).
  Нестабильный прогон (flaky: упал, при перезапуске прошёл) → passed, отметь flaky, если поле есть.
- Сообщение: на каком шаге падение и текст ошибки, вывод анализа (дефект продукта / проблема теста / окружение),
  число самовылеченных локаторов, браузер.
- Если есть результаты по шагам — передай их шагами результата.
- Ничего не удаляй и не закрывай чужие запуски. Вызови done с ID результата или запуска.
